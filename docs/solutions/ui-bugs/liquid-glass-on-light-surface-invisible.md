# 浅底液态玻璃配方：为什么白 sheen 会隐形，怎么配才可见

## Context（v13 实战全过程）

v13 任务：让液态玻璃档右键菜单与经典档「一眼可辨」（此前两档肉眼无差）。约束：菜单是功能
浮层，底色须 ≥0.95 近不透明防透字，玻璃感只能从光影语言来。

首版配方照搬液态 `.app` 面板的招牌笔触——**白色多档 sheen + 顶部镜面高光 0.9**。
CDP 截图像素采样实测：液态 vs 经典 ΔRGB 仅 6~7（250 vs 254），肉眼无差，自验阶段即推翻。

## Guidance（有效配方三支柱）

在**近白表面上**，玻璃感不能靠「叠加白光」（白上叠白，天花板 255 就在头顶），要改走
**改变底霜本身 + 制造暗部**：

1. **冷灰底霜**：底色从 247 纯白系降到 241 冷灰（R<B，如 rgb(241,242,248)），与经典档
   死平 254 拉开基线；同面板 236 家族保持「外壳比内容层更灰」的层级语言。
2. **底部暗带 + 底部内阴影**：`linear-gradient(180deg, transparent 50%, rgba(30,34,45,0.09))`
   + `inset 0 -1.5px 2.5px rgba(0,0,0,0.2)`——玻璃厚度感来自底沿收暗，浅底上这是
   对比度预算最富裕的方向（可做出 20~25 级摆幅）。
3. **描边对比**：深色发丝边线 0.16（浅底上白描边不可见，须深描边——v8⑫ 先例）。

白色 sheen 仍可保留（顶缘高光带 252），但它只是第四信号，不承担辨识度主力。

校准纪律：**每档配方改动都跑像素采样**（菜单中列纵扫顶/中/底三点 RGB），不靠肉眼；
round-44 评审用同一方法发现「浅档弱于深档」，round-45 用同一方法判定修复「到位且未过火」
（底带最深处 L≈229 仍属高明度区，冷色调 B≥R+4 无脏感，末项文字对比 13.5:1）。

## Why This Matters

- 深色档直觉配方（白 sheen+高光）在浅色档**系统性失效**——同一套「玻璃语言」跨明暗档
  必须换算载体：深底上「加白」可见，浅底上「造暗+变灰」才可见。
- 「再加深」有尽头：round-45 明确「当前点位是可辨与发脏之间的正确平衡点」——底带再深
  开始牺牲玻璃干净度。想再增强浅档先读 round-44/45 档案。
- 防透字纪律（≥0.95）与辨识度不冲突：透明度不动，全部差异走不透明层的颜色/渐变/阴影。

## When to Apply

- 液态材质新增浅色表面组件（面板/菜单/抽屉之外）时，先像素采样经典档基线，按三支柱配。
- 任何「看不出变化」类视觉任务：先用像素差值确认「变化量」存在（ΔRGB <10 基本肉眼无感），
  再谈质感；实测优先于设计直觉。

## Examples（v13 终稿，src/styles.css 浅色液态菜单段）

```css
background:
  linear-gradient(160deg, rgba(255,255,255,.62) 0%, rgba(255,255,255,.26) 38%,
    rgba(255,255,255,.08) 64%, rgba(255,255,255,.2) 100%),      /* sheen（第四信号） */
  linear-gradient(180deg, rgba(30,34,45,0) 50%, rgba(30,34,45,.09) 100%),  /* 底部暗带（主力②） */
  rgba(241,242,248,.95);                                        /* 冷灰底霜（主力①）+ 防透字线 */
box-shadow: var(--shadow),
  inset 0 1px 0 rgba(255,255,255,.9),                           /* 顶高光带 */
  inset 0 -1.5px 2.5px rgba(0,0,0,.2),                          /* 底部厚度（主力②） */
  inset 0 0 0 .5px rgba(0,0,0,.16);                             /* 深描边（主力③） */
```

实测效果（round-45 评审像素裁定）：浅档液态 顶 252→中 244→底带 229-237（冷调 B-R≈+4）
vs 经典通体平直 254——结构性明暗齐备，一眼可辨。
