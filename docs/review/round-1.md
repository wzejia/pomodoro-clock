# Round 1 评审原文（独立评审子智能体，仅提供四态截图+评审标准）

评审基于四张截图原图 + 对关键区域（计时区、按钮排、统计卡、周柱图、设置区、迷你胶囊）的放大裁切核对。

## P1（必须修）

**1. 周柱图空数据日显示红色短条，像"有数据"**
- 截图：round-1.png、round-1-dark.png（周柱图区域）
- 问题：一、二、三有数据的红色高柱之外，四、五、六、日四个空数据日都画了一截红色短横条。红色在本应用里是"强调/进行"语义，空日也染红，既误导（远看以为每天都有记录）又让整排柱子一片红，是面板里最糙的一处。
- 建议：空数据日不绘制柱子，改为基线位置一个 3-4px 中性灰圆点（浅主题 `rgba(0,0,0,0.18)`，深主题 `rgba(255,255,255,0.22)`）；有数据日保留红柱。

## P2（建议修）

**2. 迷你胶囊右侧红色暂停按钮几乎贴边，左右留白不对称**
- 建议：按钮直径收敛为胶囊高度的 55-60%，右侧内边距与左侧对齐（建议左右各 10-12px）；暂停图标两竖条也随之缩小。

**3. 迷你胶囊"红点 + 红圆钮"双红竞争**
- 建议：阶段点缩小到 6px 并降透明度（或改为胶囊左侧 2px 宽的红色竖条），把唯一的红色圆形留给暂停按钮；休息阶段点再换对应阶段色。

**4. 大数字与统计数字字重过重**
- 建议：主计时降到 500-600，统计卡数字 600；按钮文字从 Bold 降到 Medium/Semibold。

**5. 周柱图有数据日全部实心饱和红，数据区噪音过大**
- 建议：柱子用强调色 55-70% 透明度，或改中性灰柱 + 仅"今天"用红色高亮（Apple 健身图表的惯例）；红色填充只保留给真正可点击的主按钮。

**6. 浅色主题下「重置/跳过」按钮与统计卡片同为纯白填充，可点击感弱**
- 建议：次级按钮改为浅灰填充 + 无底边阴影，卡片保持纯白并加极淡描边或投影，让"容器"与"控件"分层。

**7. 计时下方进度条过细，红色进度段几不可见**
- 建议：轨道加粗到 3-4px、两端全圆角；或把进度语义合并进大数字。

**8. 周柱图内疑似有一条虚线横向穿过柱身**
- 若是网格/参考线，降到 8-12% 透明度并置于柱后，或删除。

**9. 柱图无容器，与上方三张统计卡片的"卡片化"语言不统一**
- 建议：柱图与设置区各加与统计卡同圆角、同填充的容器卡，面板内统一为"面板底 + 悬浮卡片"两级层级。

## 通过项

- 圆角体系：面板(~24px)/卡片(~14px)/按钮(~12px)/分段控件(~8px) 尺度递减合理。
- 深色主题整体成立，分段控件为教科书式 iOS Segmented 形态。
- 三张统计卡等宽等高间距均匀，设置区排布整齐，迷你胶囊两主题适配正确。

## 总评

骨架和信息架构已是苹果的样子，但「红色用法」还没有苹果的纪律——红既是强调色又是填充色、连空数据都红，先把 P1 的空日红条和 P2 的双红/全红柱收掉，质感能上一整档。
