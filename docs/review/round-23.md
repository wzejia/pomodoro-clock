# 视觉评审报告 — round-23（六张截图，双主题）

评审基准：Apple Human Interface Guidelines（间距节奏、字重克制、颜色克制、控件语义、对比度）。已对可疑区域做 3x 放大核实，缩略误读已排除。

**无 P1。** 六张截图在间距一致性、对齐、控件体系、双主题映射上未发现视觉不一致或可用性阻断项。

## P2（可改进）

1. **深色抽屉 · 开关「开」态缺乏着色**（round-23-drawer-dark.png）
   「自动开始下一阶段」开关处于开态（滑块居右），但轨道为中性深灰，与卡片底色反差极小，开/关状态几乎只能靠滑块位置辨认。Apple 惯例中开态轨道应有着色（系统绿或应用强调色）。建议开态轨道使用应用红色强调色（或降低明度的暗色版红），双主题语义一致。浅色截图中开关为关态，无法横向验证浅色开态是否有着色——若浅色开态同样无着色，则同属此条。

## P3（偏好）

2. **循环圆点视觉权重偏低**（round-23.png / round-23-dark.png）
   进度条下方 4 枚循环指示点均为细描边空心圆，尺寸小、对比弱。当前状态全部未填充（数据上合理），但作为唯一的循环进度指示，空心态在深色背景上略「隐身」。建议确认「已填充/当前」态的样式有足够辨识度；若活动态也只是换描边色，建议改为实心填充。

3. **进度条近 0% 时呈现为孤立红点**（round-23.png / round-23-dark.png）
   运行初期红色填充量极小，视觉上读作「灰轨左端的一颗红圆点」而非「填充的起点」，有轻微歧义。可考虑给填充设最小可见宽度，或让起始圆头与轨道左端圆头重合过渡。属吹毛求疵级。

4. **深色分段控件未选中项对比度偏弱**（round-23-drawer-dark.png）
   「浅色/深色」分段控件中，未选中的「浅色」文字为中灰，压暗背景上可读但吃力，接近次要文字的最低可接受线。选中态（亮药丸+白字）语义清晰，整体无碍，可顺手把未选中文字提亮半档。
