# Round 12 评审原文（独立评审子智能体，仅提供四态截图+评审标准）

> 本轮 = 领导 4 项修复（面板高度 441、动画单源 340ms、齿轮入底栏、图标候选 A）后首轮。

## P1（必须修）
无 P1。

四态截图在布局结构、控件形态、字号层级上跨主题一致：浅色/深色展开面板的三按钮行、统计三卡、周图、底部齿轮+收起箭头的位置与形态完全对应；迷你胶囊两主题同样一致。没有发现可用性阻断。

## P2（可改进）
1. **浅色主题下迷你胶囊是深色底**（round-12-mini.png）：胶囊在两主题下都是近黑炭底+白字，而展开面板浅色是白玻璃。点击胶囊展开成面板时材料跳变明显（黑→白），同一应用的两种形态缺少视觉连续性。要么浅色主题胶囊也用浅色材料，要么确认这是有意的"常黑胶囊"设计并写进设计约定。
2. **毛玻璃透度过高、模糊不足**（round-12.png / round-12-dark.png 面板头部与区块间隔区）：背景终端文字透过面板较清晰地可读，尤其在"专注"标题和 24:56 周围形成视觉噪声。Apple 的 material 标准是"透出色彩与动态、不读出内容"，建议提高 backdrop blur 半径或叠加一层不透明度更高的 tint。
3. **进度条在浅色面板几乎不可见**（round-12.png 计时器下方）：轨道是近白细线叠在白玻璃上，只剩一个红色小圆点可读。深色下轨道可见性尚可，浅色下建议加深轨道对比度。
4. **收起入口与设置入口偏小偏弱**（两面板底部）：齿轮（左下）与上箭头（底部居中）都是小号低对比灰，首次用户需要扫一圈才能发现。不算阻断（位置符合直觉、不干扰主功能），但对比度可再提一档，尤其浅色态。

## P3（偏好）
1. **底部工具区左右不对称**：齿轮在左下、箭头居中、右下留空。可考虑右下配一个占位或把箭头也右移，或接受现状（Apple 也常用非对称工具排布）。
2. **"休息"按钮带图标、"重置"纯文字**：同排按钮一个有图标一个没有，略显不齐；要么都加要么都不加更整齐。
3. **周图红色柱圆角与统计卡圆角**目测协调，但柱体与卡片圆角半径若有 token 化统一会更"系统感"。
4. **迷你胶囊无进度暗示**：运行中胶囊只有时间+暂停，可考虑让胶囊底缘或文字色极轻微地传达进度（纯偏好，现状已够克制）。

## 做得好
计时数字的字号与字重层级非常果断，一眼即主功能；配色克制——全界面只有红一个强调色，运行状态、主按钮、图表数据共用同一红，语义统一；展开面板信息分区（计时/操作/统计/周图）节奏清楚，无装饰性元素。

## 总评
这是一套已达"像 Apple 做的"标准的界面：克制、层级清晰、跨主题一致性好。剩余问题集中在材料（浅色胶囊与面板的材料跳变、毛玻璃模糊偏弱）和次要入口的对比度上，均属打磨范畴，无 P1 阻断项。
