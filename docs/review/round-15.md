# Round-15 评审（2026-08-13）

> 评审对象：round-15 四态截图 + ctx/ 右键菜单三态。独立评审子智能体（只给截图+Apple HIG，不给实现）。

## 评审原文（findings）

- [P1] **浅色展开面板·次级按钮体系不一致**：「重置」按钮底色几乎与面板底色相同（近乎无填充），而「休息」按钮有明显的浅灰胶囊底；深色主题下两键底色完全一致。同一按钮体系在浅色下出现两种视觉重量，违反自身一致性。
- [P1] **底部收起键对比度过低（浅色尤甚）**：展开面板底部唯一的收起入口「∧」在浅色主题下为浅灰圆底+中灰箭头，整图下几乎不可见；深色主题稍好但仍偏弱。这是唯一收起路径，可发现性不足构成可用性阻断。
- [P2] **设置抽屉高度未适配内容**：抽屉沿用展开面板高度，内容只有五行，下半截大面积空白，头重脚轻。
- [P2] **计时下方进度条轨道在浅色主题近乎隐形**：红色进度点清晰，但轨道线对比度极低。
- [P3] **周图「今日」标签深浅主题处理不对称**：深色下是白底反色小徽章，略显突兀。
- [P3] **右键菜单遮挡内容**：Windows 右键菜单常规行为，瞬时态，可接受。
- [P3] **设置入口仅藏在右键菜单**：按苹果瞬时小面板惯例可接受，维持现状。

## 分诊与处置

| 项 | 裁决 | 处置 |
|---|---|---|
| P1 按钮底色不一致 | **误读**（CDP 实测两键 computed background 同为 rgb(227,227,232)，系红色主键邻接+缩图造成的视错觉） | 顺手加固：浅色 --btn-secondary #e3e3e8→#dcdce2 加深一档降错觉 |
| P1 收起键对比度 | 成立（R13 残留 P2 升级） | 箭头色 var(--text-secondary)→var(--text)，底色随 --btn-secondary 加深 |
| P2 抽屉空白 | 成立 | drawer gap 6→10、setting-row 纵向 padding 9→12，内容拉开节奏 |
| P2 进度轨道 | 成立 | 浅色 --progress-track 0.16→0.22 |
| P3×3 | 记录在案不改 | —— |
