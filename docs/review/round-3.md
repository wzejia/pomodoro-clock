# Round 3 评审原文（独立评审子智能体，仅提供四态截图+评审标准）

## P1（必须修）

**P1-1 周柱状图：柱子未锚定基线，呈「悬浮胶囊」**
柱子上下四角等大圆角，底部圆角使柱底与基线出现视觉缝隙；空天小圆点却端坐在基线上——「点贴线、柱悬浮」两套逻辑并存。Apple Health/屏幕使用时间一律「顶部圆角、底部直角贴基线」。
建议：柱子仅顶部两角圆角，底部直角精确贴基线；基线 0.5–1px 分隔线色显式画出。

**P1-2 浅色展开面板材质透明度过高，桌面文字压穿 UI 文字**
桌面代码文字直接透过面板和统计卡片，与界面文字重叠，可读性受损。Apple vibrancy 材质在任何背景下保证前景对比度。
建议：浅色面板底不透明度 0.85→0.92+，或加大模糊半径 + saturate。

**P1-3 操作按钮行三种规格并存**
「暂停」宽大红色实底胶囊，「重置/跳过」明显更窄且底色淡到近乎消失。
建议：三按钮统一高度圆角；次级按钮用 Apple 系统填充色（浅 rgba(120,120,128,0.16)、深 0.24）；整行只保留一种强调方式。

## P2（建议）

- **P2-1 字重过重**：计时数字改 300–400，统计数字 600，标签 400–500。
- **P2-2 步进器顺序别扭「− 25 分钟 +」**：改 [−][25 分钟][+] 连续 pill 组。
- **P2-3 红色语义泛化**：暂停不是破坏性操作，红底按钮=删除/结束；暂停钮改黑/深灰实底，红色只留阶段色与柱图；迷你态双红竞争同解。
- **P2-4 分组标题不齐**：统计区加「统计」、图表加「本周」小标题（13px 次级色）。
- **P2-5 迷你胶囊重心右偏**：按钮直径缩到胶囊高 ~76%。
- **P2-6 深色柱图红色略荧光**：深色柱色降亮/降饱和 5–8%。

## 通过项
圆角尺度统一克制；「外观」分段控件标准；统计三卡层级正确；强调色总量克制；迷你胶囊形态成立。

## 总评
骨架和克制感已经对了，但柱图「悬浮胶囊」、浅色面板被背景文字压穿、按钮行三规格三处硬伤让它停在「像 Apple 的仿品」——修掉 3 条 P1 与字重、步进器两条 P2 后质感能上台阶。
